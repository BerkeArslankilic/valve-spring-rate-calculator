# Valve Spring Rate Calculator

I originally wrote this to be the software for an advanced valve spring tester machine for my graduation project. I ended up shelving the actual machine build, but the code still works to translate Hooke's Law into practical real world numbers.

## Features
- **Real-Time Force Curve:** Dynamically graphs the spring's force curve using Chart.js.
- **Seat & Open Pressure:** Instantly translates spring rate and installed height into actual valvetrain control numbers.
- **Coil Bind Warning System:** Highlights bind clearance in red if it falls below the universally safe margin (0.060" / 1.5mm) to prevent catastrophic engine failure.
- **Unit Conversion:** Flawlessly toggle between Imperial (lbs/in) and Metric (kg/mm) math on the fly.
- **Dark Mode UI:** Sleek, high-contrast dashboard designed for gearheads and engineers.
